Personal Shopping Agent System

An intelligent full-stack Python application that automates product data retrieval, performs multi-store price comparisons, analyzes genuine customer feedback with NLP/LLMs, and generates transparent recommendations.

Responsible & Ethical Data Retrieval

Online shopping sites have anti-bot protections and varying terms of service. This system follows strict ethical guidelines:

  • No CAPTCHA Bypassing: When a site presents an anti-bot challenge or 403 status, the scraper logs the event gracefully and falls back to verified catalog demonstration records.
  • Polite Request Throttling: External HTTP requests apply strict 6-second timeouts with realistic browser headers to prevent denial of service.
  • Isolation: If one e-commerce platform fails or throttles, other sources continue to return results without crashing the application.
Transparent Recommendation Algorithm

Unlike black-box models, recommendations are computed deterministically using standard normalized mathematical components:

Score = (0.40 × PriceScore) + (0.25 × RatingScore) + (0.15 × ReviewVolume) + (0.10 × Sentiment) + (0.10 × Specs)

Dynamic Redistribution: If sentiment or technical specifications are unavailable, their weights are proportionally redistributed across available metrics so products are never unfairly penalized.

End-to-End System Workflow
  1. User Input & Validation: User submits a search query and optional filters. Input is sanitized and validated in validators.py.
  2. Multi-Source Retrieval: ProductService queries Amazon, Flipkart, Croma, and Reliance Digital modules concurrently or sequentially.
  3. Normalization & Matching: Raw responses are normalized into a unified schema. ProductMatcher groups verified equivalent items.
  4. Storage & Price History: SQLite database stores product records and logs price observations in PriceHistory for trend tracking.
  5. Comparison & Calculations: ComparisonService identifies lowest price, calculates absolute and percentage savings, and creates a specs matrix.
  6. AI Review Summarization: ReviewAnalyzer processes customer feedback using Gemini LLM or local NLP fallback.
  7. Recommendation Scoring: Recommender scores products to crown Lowest Price, Best Rated, and Best Overall winners.
